# Versions des données

Chaque version conserve deux fichiers immuables : `<id>.json` (métadonnées et empreintes) et `<id>.zip` (exports figés, citation et journal).

Ne pas modifier ni supprimer une version publiée. Ajouter une nouvelle version et documenter une correction ou un retrait justifié. Une archive technique ne constitue pas une validation historique supplémentaire.
