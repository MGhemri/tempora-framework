# Évaluation humaine des rapprochements

Un fichier `QA_<identifiant>.json` par paire, selon `schemas/duplicate-assessment.schema.json`.
Les annotations revues exigent des passages sources, les empreintes des fiches et des sources ainsi qu’une approbation liée au contenu.

Ce répertoire est initialement vide. Les exemples synthétiques restent dans les tests ; aucune étiquette historique n’est inventée pour améliorer les métriques.
