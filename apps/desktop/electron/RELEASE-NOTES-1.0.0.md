# TEMPORA Desktop 1.0.0 — Candidate release notes

**Source candidate only — not signed, certified or published.**

## English

TEMPORA Desktop 1.0.0 prepares an offline Windows research workspace
built on the TEMPORA Framework 3.0.0 scientific engine.

- GeoLab: interactive coordinates, fitted viewport, zoom and pan; no
  unverified map basemaps.
- Chronos: precise civil-day rendering of declared dates, preserving
  uncertainty and unknown event ends.
- GraphLab: deterministic declared-relation graph with keyboard-accessible
  selection of correctly typed references.
- TEMPORA Assistant: input inspection, mapping, technical previews, conflict
  quarantine and human-gated in-memory staging, without automatic import.
- Read-only research workbench and bundled synthetic/ALNOP examples offline.

Research decisions remain human. Experimental scientific writing,
TensorFlow and automatic Store updates are not enabled.

## Français

TEMPORA Desktop 1.0.0 prépare un environnement de recherche Windows hors
ligne, fondé sur TEMPORA Framework 3.0.0.

- GeoLab : coordonnées, cadrage local, zoom et déplacement, sans fonds
  cartographiques non vérifiés.
- Chronos : dates grégoriennes au jour près, incertitudes et fins inconnues.
- GraphLab : relations déclarées, disposition déterministe, navigation
  au clavier par références typées.
- TEMPORA Assistant : inspection, mapping, simulation, conflits et
  mise en mémoire soumise à des décisions humaines.
- Workbench en lecture/analyse, exemples synthétiques et ALNOP hors ligne.

La sauvegarde scientifique expérimentale, TensorFlow et la publication
automatique Microsoft Store restent désactivés.

No GitHub Release, Store submission or public stable status is authorized
solely by these draft notes.
