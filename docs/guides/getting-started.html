Démarrage

Node.js 20 ou supérieur et npm suffisent pour le parcours synthétique.

Exemple
git clone https://github.com/MGhemri/tempora-framework.git
cd tempora-framework
npm ci
npm run test:e2e:synthetic

Le parcours teste le noyau sur deux profils fictifs et installe le paquet dans un projet indépendant. Il couvre l’import, la revue, la publication et la consultation par l’API locale.

Le tarball de développement s’installe localement. Consultez le guide SDK et CLI pour le construire et le guide d’ingestion pour préparer vos premiers imports.
