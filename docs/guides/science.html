Méthodologie

Une notice distingue les sources, les assertions et les incertitudes. Les références documentent les passages consultés lorsqu’ils sont connus. Les informations manquantes restent explicites.

Les rapprochements de titres ou de noms préparent une revue humaine. Les statistiques de couverture mesurent la documentation disponible dans le corpus étudié. Les droits de redistribution et les citations s’établissent pour chaque corpus.

Consultez les guides d’analyse, de revue et de publication.
