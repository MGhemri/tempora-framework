Code de conduite

Respecter les personnes, y compris en cas de désaccord historiographique. Critiquer les arguments avec leurs sources. Harcèlement, insultes, discrimination et publication de données personnelles sans consentement ne sont pas acceptés.

Les mainteneurs peuvent demander une reformulation, masquer un contenu ou restreindre une participation en motivant leur décision sans reproduire les données sensibles. Pour un incident public, contacter un mainteneur par le canal de contact du projet ; ne pas republier de données personnelles dans une Issue. Un réexamen peut être demandé avec les éléments pertinents.

العربية: احترم الأشخاص وناقش الحجج بمراجعها. يُمنع التحرش والإهانة والتمييز ونشر البيانات الشخصية دون موافقة. يمكن طلب إعادة النظر في قرار الإشراف مع تقديم الأدلة ذات الصلة.
